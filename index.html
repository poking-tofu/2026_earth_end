COURSE OVERVIEW

一、課程概述

本課程為期五週（7/17 - 8/14），核心主軸從環境建置與工具啟動，經折射震測與資料分析，最終發展至 CLIL（內容和語言整合學習）防災探究與英文成果發表。課程內容結合地球科學專業知識、資訊科技工具以及雙語教學設計，旨在全面實務應用地球物理探勘技術與教學發展。

CORE LEARNING

三、核心技術與理論學習重點

1. 網頁建置與雲端部署

  • 使用 Gemini 輔助生成 index.html。
  • 利用 GitHub 儲存技術文件與程式碼。
  • 透過 GitHub Pages 將靜態網頁公開部署。
  • 把教案與學習成果轉化為可分享的網站。

2. AI 代理與自動化工具應用

  • Google Antigravity IDE：可直接操作電腦本機與環境檔案，自動生成內容並寫入資料夾，也支援人工檢視與編修。
  • Google Apps Script：串接 Google Forms 與 Sheets，建立資料收集與自動寄信流程。

3. 地球物理震測實驗與原理

  • 透過人工震源與地震儀陣列探測地下構造。
  • 近距離測站通常較早接收到直達波。
  • 遠距離時，折射波進入深層高速地層傳播，可能比直達波更早到達。
  • 利用到時差異與波速推測地下介質。

4. 建築共振反應

  • 地震波包含不同頻率成分。
  • 不同地質結構會影響震波傳遞與放大。
  • 不同高度建築對不同頻率震波反應不同。
  • 以黏土與竹籤模型觀察建築共振現象。

5. CLIL 雙語教案開發與提示詞工程

善用 IRIS 平台等國外開源資源，結合提示詞工程，產出適合國小高年級（5～6 年級）的雙語地震教案。

四、互動式學習整理

切換不同主題，快速回顧課程中最重要的工具與科學概念。

GitHub Pages：把學習成果變成公開網站

使用 HTML 建立內容，再將檔案上傳至 GitHub repository，透過 GitHub Pages 即可部署成可公開瀏覽的靜態網站。

Antigravity IDE：AI Agent 操作檔案

可直接在本機環境中建立、修改與整理檔案，同時保留人工檢視與編輯的空間，適合製作報告、教案與網頁。

折射震測：為什麼遠處折射波可能先到？

折射波雖然走的路較長，但若進入速度更快的深層介質，超過一定距離後，其總旅行時間可能比直達波更短，因此會先被遠距離測站接收。

Google Apps Script：自動收集與寄信

利用表單收集姓名與 Email，回覆資料自動寫入 Google Sheets，再由 Apps Script 寄送確認信給填表者與教師。

CLIL 教案：地球科學 × 英文

將震央、震源、地震定位等科學概念轉化成生活化活動，搭配核心單字、簡單句型、影片與互動挑戰，適合國小高年級。
